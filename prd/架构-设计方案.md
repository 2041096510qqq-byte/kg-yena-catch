### 页面列表

| 页面 | 代码标识 | 路由状态 | 职责 | 主要区域 |
|------|---------|---------|------|---------|
| 主界面 | `HomePage` | `gameState=IDLE` | 难度选择 + 皮肤入口 + 开始 | 难度面板、皮肤按钮、开始按钮 |
| 游戏界面 | `GamePage` | `gameState=PLAYING/PAUSED/COUNTDOWN/STUNNED/FEVER` | 核心游玩 | HUD、YenaStage、CoreStage、PlayerArea |
| 结算浮层 | `ResultModal` | `gameState=RESULT` / ModalLayer | 结算展示 | 评分、统计、再来一局、分享 |
| 暂停浮层 | `PauseModal` | `gameState=PAUSED` / ModalLayer | 暂停操作 | 继续、退出 |

## 组件层级

```
App.tsx (页面路由状态机 — 由 gameState 驱动)
├── HomePage                         # gameState=IDLE
│   ├── DifficultySelector           # 难度三选一
│   ├── SkinButton                   # 皮肤入口
│   └── StartButton                  # 开始按钮
│
├── GamePage                         # gameState≠IDLE 且 ≠RESULT
│   ├── HUD                          # 顶部信息栏
│   │   ├── TimerDisplay             #   倒计时显示
│   │   ├── ScoreDisplay             #   实时分数
│   │   ├── ComboDisplay             #   Combo 数 + 称号
│   │   └── FeverGauge               #   Fever 槽进度条
│   ├── YenaStage                    # Yena 立绘区（丢出动画）
│   ├── CoreStage                    # 游戏舞台（DOM ref 驱动）
│   │   ├── ElementNode × N          #   下落元素（绝对定位，ref 操作）
│   │   └── ParticleNode × M         #   粒子（绝对定位，ref 操作）
│   └── PlayerArea                   # 底部操作区
│       ├── PlayerSprite             #   粉丝小人精灵
│       └── PauseButton              #   暂停按钮
│
├── CountdownOverlay                 # gameState=COUNTDOWN（3-2-1 大字）
│
├── ModalLayer                       # 全局弹窗层（与页面平级）
│   ├── ResultModal                  #   modal_result 母版
│   ├── PauseModal                   #   modal_pause 母版
│   └── DifficultyModal              #   modal_difficulty 母版
│
└── FxLayer                          # 全局浮层（瞬时反馈，不占版面）
    ├── FloatScoreText × N           #   +1/+5/-2 浮动分数
    ├── ComboTitlePopup              #   Nice!/Great!/Amazing!/CATCH CATCH!
    ├── FeverOverlay                 #   FEVER! 大字 + 金色粒子容器
    └── StunOverlay                  #   眩晕边缘泛红 + 星星旋转
```

> 简单音效（点击/成功/错误/奖励）由代码端 `AudioGenerator`（Web Audio 合成）处理，不写本节。仅当 PRD 明确要求 BGM/复杂音效时列。

## 动画参数

| 动画 | 类型 | 时长 | 缓动 | 说明 |
|------|------|------|------|------|
| 爱心下落 | CSS transform translateY | 由掉落速度决定（2-3s 穿越掉落区） | linear | 垂直下落 + 正弦水平摇摆 |
| 道具下落 | CSS transform translateY + rotate | 由掉落速度决定 | linear | 垂直下落 + 逆时针旋转 + 拖尾粒子 |
| 炸弹下落 | CSS transform translateY | 由掉落速度决定 | linear | 直线下落 + 引线火花粒子 |
| 小人移动 | CSS transform translateX | 实时跟随 | ease-out ~0.15s | 带惯性缓动 |
| 接住爱心爆散 | CSS keyframes (scale+opacity) | 400ms | ease-out | 粉红粒子向外爆散后消失 |
| 接住道具爆散 | CSS keyframes (scale+opacity) | 500ms | ease-out | 金色星星爆散后消失 |
| 炸弹爆炸 | CSS keyframes (scale+opacity) | 400ms | ease-out | 灰色烟雾扩散后消失 |
| 浮动分数 (+1/+5/-2) | CSS transform translateY + opacity | 800ms | ease-out | 从碰撞点向上飘 60px 后淡出 |
| Combo 称号弹出 | CSS keyframes (scale 0→1.2→1) | 600ms | cubic-bezier(0.34,1.56,0.64,1) | 弹性缩放 |
| Fever Time 触发大字 | CSS keyframes (scale+translateY+opacity) | 1200ms | ease-out | FEVER! 从中心弹出→上飘→淡出 |
| Fever Time 金色粒子 | CSS keyframes (translate+opacity) | 1500-2500ms | linear | 全屏随机位置向下飘落 |
| Fever Time 背景过渡 | CSS transition background-color | 300ms | ease-in-out | 背景渐变过渡到金粉色调 |
| 眩晕小人摇晃 | CSS keyframes translateX | 循环（周期 0.5s） | ease-in-out | 左右摇摆 ±10px |
| 眩晕星星旋转 | CSS keyframes rotate | 循环（周期 1s） | linear | 小人头顶旋转星星 |
| 眩晕边缘泛红 | CSS transition box-shadow | 200ms | ease-in | 画面边缘红色光晕 |
| 无敌闪烁 | CSS keyframes opacity | 循环（周期 0.2s） | steps(2) | 0.5 秒快速闪烁 |
| 倒计时闪烁（最后 10s） | CSS keyframes opacity + color | 循环（周期 1s） | steps(2) | 红色闪烁 |
| 倒计时 3-2-1 | CSS keyframes scale+opacity | 每字 1000ms | ease-out | 数字放大→缩小→消失 |
| 结算星级入场 | CSS keyframes scale + animation-delay | 每星 200ms 延迟 | cubic-bezier(0.34,1.56,0.64,1) | 逐个弹性弹出 |
| 弹窗入场 | CSS transition opacity+transform | 300ms | ease-out | 遮罩淡入 + 面板 scale(0.9→1) |
| 弹窗退场 | CSS transition opacity+transform | 200ms | ease-in | 遮罩淡出 + 面板 scale(1→0.9) |
| Yena 丢出动画 | CSS keyframes（精灵帧动画） | 循环（周期与掉落间隔同步） | steps() | Yena 立绘的手臂丢出动作 |
