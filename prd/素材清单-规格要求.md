## 三、占位符实现方案（开发阶段）

在素材就绪前，使用以下占位方案保证游戏可运行：

| 类别 | 占位方案 |
|------|---------|
| Yena 立绘 | `<div>` 灰色矩形色块 + 文字 "YENA" |
| 小人 | `<div>` 60×60px 圆角矩形，CSS 背景色区分皮肤 |
| 爱心 | `<div>` 50×50px 粉色圆形 |
| 道具 | `<div>` 50×50px 金色方形 |
| 炸弹 | `<div>` 50×50px 黑色圆形 + 红色边框 |
| 粒子 | CSS `@keyframes` + `box-shadow` 实现，无需图片 |
| 按钮 | CSS + 文字，不使用图片 |
| 弹窗背景 | CSS 半透明背景 + 圆角，无图片 |
| 星级 | CSS + Unicode 字符 `★☆` 或 SVG 实现 |
| BGM | 留空或用 Web Audio 合成简单音调 |
| SFX | Web Audio API 合成短促音效 |

## 五、推荐素材获取方向（供内部参考）

> 以下为建议，非强制。实际采购/制作时按需调整。

- **Yena 立绘**：需画师绘制，建议半身像+手臂特写+多表情
- **小人皮肤**：需 2D 动画师，逐帧或骨骼动画
- **元素图标**：找像素画师或扁平化设计师
- **BGM/SFX**：可联系音乐人制作，或使用有版权音乐库授权
- **粒子特效**：程序化生成可替代图片粒子

---

> ⚠️ **优先级建议**：先提供 Yena 立绘和小人皮肤（影响主要视觉体验），其他 UI/粒子可后期补齐。
